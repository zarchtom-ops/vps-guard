# VPS Guard 安全模型

## 保护目标

- 让管理员快速发现 SSH、主机防火墙、Fail2Ban 和公网监听端口的风险。
- 将面板发起的变更限制在显式动作白名单内，并保留本机追加式审计记录。
- 在不上传认证日志、端口信息和凭据的前提下提供本地安全可见性。

## 信任边界

面板运行在被管理主机上，默认仅监听 `127.0.0.1`。访问者必须持有安装时生成的令牌；远程访问建议通过 SSH 隧道。面板不会替代云安全组、操作系统审计或集中式日志平台。

## 非目标

- 不提供互联网端口扫描、漏洞利用、恶意流量生成或自动化攻击能力。
- 不承诺发现所有入侵；日志轮转、容器网络和云防火墙可能在面板视野之外。
- 不自动根据统计结果封禁地址。封禁属于有影响的变更，必须由管理员确认。

## 报告问题

请不要在公开 Issue 中粘贴访问令牌、私钥、真实认证日志或公网地址。报告安全问题时，描述受影响版本、复现步骤和最小化日志片段。
